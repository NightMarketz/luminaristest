Como usar a demonstração da API
 Neste ambiente é demonstrado cenários de dados simulados (mock objects) e com isso entender o funcionamento da API. Abaixo segue como utilizr esse modo de demonstração: 
 Acesse o menu Demonstração 
 Escolha o método (endpoint) a testar
 Clique em Try it Out
 Insira os cabeçalhos que desejar e/ou altere o conteúdo do corpo da requisição
 Clique em Execute
 IMPORTANTE
 A chamada da API Trial é apenas para demonstração. As APIs disponíveis e suas respectivas URLs (endpoints) para consumo são disponibilizadas (através da documentação dos seus respectivos swaggers) na seção Referência da API.
