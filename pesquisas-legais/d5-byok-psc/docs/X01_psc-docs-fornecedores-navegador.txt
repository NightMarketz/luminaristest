## SOLUTI / BirdID — API do PSC (docs.vaultid.com.br, índice em https://docs.vaultid.com.br/workspace/llms.txt)
- https://docs.vaultid.com.br/workspace/cloud/api/manutencao/cadastro-de-aplicacao.md
  "POST https://api.birdid.com.br/v0/oauth/application" — corpo: name, comments, redirect_uris, email, client_secret, client_id
  (sem certificado). Resposta: "Aplicacao cadastrada com sucesso".
- https://docs.vaultid.com.br/workspace/cloud/api/manutencao/auto-cadastro-de-aplicacao.md
  "É um serviço público, que não requer uma pré-autenticação, o registro da aplicação com assinatura digital (Com um
  Certificado Digital ICP Brasil - SSL) deve ser feito através do protocolo JWS"
- https://docs.vaultid.com.br/workspace/cloud/api/uso-de-certificado/assinatura-digital.md
  "POST https://api.birdid.com.br/v0/oauth/signature"; "hash_algorithm: Object Identifier (OID) do algoritimo de hash.
  Por exemplo, para SHA256 utilize o OID 2.16.840.1.101.3.4.2.1"; "RAW: Assinatura PKCS#1 v1.5, resultado direto da
  operação RSA/DSA sobre o hash". Não lista os OIDs aceitos.
  "Para abstrair o uso de recursos de criptografia [...] Conheça também os middlewares: PKCS11, CSP (Microsoft Crypto
  API), Engine OpenSSL, JCA/JCE."
- https://docs.vaultid.com.br/workspace/middleware/pkcs-11.md
  "no cenário do uso de certificado em nuvem é utilizado principalmente para autenticação, listagem de objetos e
  assinatura." C_Sign / C_SignInit: "OK".
- https://docs.vaultid.com.br/workspace/middleware/engine-openssl.md
  "a engine OpenSSL do BirdID é disponibilizada através do wrapper libp11 mantido pela OpenSC, esse wrapper permite o uso
  de uma engine OpenSSL a partir de um driver PKCS#11 que o BirdID já implementa nativamente."
- https://docs.vaultid.com.br/workspace/cess/api/preparacao-de-documento-s.md (BirdID Pro / CESS, produto licenciado)
  "hash_algorithm | Algoritmo de hash que será utilizado na assinatura (SHA1,SHA256, SHA384 ou SHA512)"; tipos:
  CMS, PDFSignature, CAdES, PAdES, XAdES.
- https://docs.vaultid.com.br/workspace/cess/licenca.md
  "Para que seja possível utilizar o BirdID Pro em produção é necessário uma licença."
